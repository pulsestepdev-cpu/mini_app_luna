# Запуск LUNA в Telegram — по шагам

Порядок такой: **бот → сайт на CapRover (https-ссылка) → привязать ссылку к боту → открыть в Telegram**.
Сервер для напоминаний и режима партнёра будет отдельным шагом позже, на том же CapRover.

---

## Шаг 1. Создать бота в @BotFather

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. **Имя (name)** — то, что видно в чатах:
   `LUNA · календарь цикла`
3. **Юзернейм (username)** — должен заканчиваться на `bot`. Варианты (на момент проверки были свободны):
   - `luna_moon_care_bot`
   - `luna_selfcare_bot`
   - `luna_tracker_bot`
   - `luna_ritm_bot`
4. BotFather пришлёт **токен** вида `123456:ABC...`. Он нужен будет позже для сервера.
   **Не пересылай его в чаты.** Сохрани в файл `.env` в корне проекта: `BOT_TOKEN=...` (git его игнорирует).

### Оформление бота (там же в BotFather)

- `/setuserpic` → выбрать бота → отправить `docs/telegram/bot-avatar.png`
- `/setdescription` (текст, который видно до нажатия «Старт»):

  ```
  LUNA — бережный календарь цикла и самочувствия ♡

  Отмечай месячные и настроение за пару касаний, смотри прогноз и свои закономерности, сохраняй отчёт для врача. Данные хранятся у тебя и в твоём личном облаке Telegram.

  Нажми «Открыть LUNA», чтобы начать.
  ```

- `/setabouttext` (короткое «о боте» в профиле):

  ```
  Бережный календарь цикла и самочувствия ♡ Прогнозы, инсайты и отчёт для врача.
  ```

## Шаг 2. Опубликовать приложение на CapRover

В репозитории уже есть всё нужное: `captain-definition`, `Dockerfile` (сборка + тесты → nginx) и `deploy/nginx.conf`.

1. В панели CapRover → **Apps** → создать приложение, имя например `luna`.
2. Открыть приложение → вкладка **HTTP Settings**:
   - **Enable HTTPS** (Telegram открывает мини-приложения только по https);
   - по желанию **Connect New Domain** — свой домен, например `luna.твой-домен.ru`
     (у домена должна быть A-запись на IP сервера), потом снова Enable HTTPS для него;
   - включить **Force HTTPS**.
   - Container HTTP Port оставить `80`.
3. Вкладка **Deployment** → **Method 3: Deploy from Github/Bitbucket/Gitlab**:
   - Repository: `github.com/pulsestepdev-cpu/mini_app_luna`
   - Branch: `main`
   - Username: твой логин GitHub
   - Password: **Personal access token** GitHub (если репозиторий приватный):
     GitHub → Settings → Developer settings → Personal access tokens → Fine-grained →
     доступ только к этому репозиторию, право **Contents: Read-only**.
   - **Save & Restart** → CapRover покажет **Webhook URL**.
4. GitHub → репозиторий → **Settings → Webhooks → Add webhook**:
   - Payload URL: тот самый Webhook URL из CapRover
   - Content type: `application/json`, событие — **Just the push event**.

   Теперь каждый пуш в `main` сам пересобирает и выкладывает приложение
   (если тесты упадут — сборка остановится и старая версия останется работать).
5. Открой ссылку приложения в браузере — должен появиться экран LUNA.
   Эта **https-ссылка** и есть адрес мини-приложения.

> Про GitHub Pages: это альтернатива CapRover (ссылка была бы `https://pulsestepdev-cpu.github.io/mini_app_luna/`),
> но для бесплатного Pages репозиторий должен быть публичным. Раз есть свой сервер — проще и надёжнее CapRover.

## Шаг 3. Привязать приложение к боту

1. **Кнопка меню** (слева от поля ввода в чате с ботом):
   BotFather → `/mybots` → выбрать бота → **Bot Settings → Menu Button → Configure menu button** →
   отправить https-ссылку из шага 2 → название кнопки: `Открыть LUNA`.
2. **Главное мини-приложение** (кнопка «Открыть» в профиле бота):
   `/mybots` → бот → **Bot Settings → Configure Mini App → Enable Mini App** → отправить ту же ссылку.
3. **Прямая ссылка `t.me/…/app`** (удобно делиться и закрепить):
   `/newapp` → выбрать бота → название `LUNA` → описание → фото `docs/telegram/bot-preview-640x360.png` →
   GIF пропустить (`/empty`) → ссылка из шага 2 → короткое имя `app`.
   Получится `https://t.me/<юзернейм_бота>/app`.

---

## Шаг 4. Проверить в Telegram

Открыть бота → «Открыть LUNA» и пройтись:
- приложение раскрывается на весь экран, свайп вниз при прокрутке не закрывает его;
- кнопки отзываются вибрацией, при сохранении слышен перезвон (если звук телефона включён);
- тёмная тема включается вместе с ночным режимом Telegram;
- в Профиле — фото из Telegram (если в настройках приватности фото видно всем/контактам);
- Профиль → Конфиденциальность → «Копия в облаке Telegram: сохранено …»;
- на вложенных экранах в шапке Telegram есть кнопка «Назад».

Если что-то не так — пришли скриншот, поправлю.
